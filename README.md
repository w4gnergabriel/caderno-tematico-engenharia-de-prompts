Caderno Temático: Engenharia de Prompts para IA Generativa

 Sobre o Projeto

Este projeto foi desenvolvido como parte de um desafio prático da DIO, com o objetivo de explorar a Inteligência Artificial como uma ferramenta de aprendizagem ativa.

O tema escolhido foi Engenharia de Prompts para Inteligência Artificial Generativa.

A proposta deste caderno temático é investigar como diferentes formas de escrever instruções podem influenciar a qualidade, a precisão e a organização das respostas geradas por modelos de Inteligência Artificial.

Durante o desenvolvimento do projeto, foram realizadas etapas de curadoria de fontes, formulação de perguntas estratégicas, experimentação com diferentes versões de prompts, análise dos resultados e consolidação dos principais conhecimentos adquiridos.

O NotebookLM foi utilizado como ferramenta de apoio à pesquisa e ao estudo, permitindo consultar e relacionar informações presentes nas fontes selecionadas.



Objetivos

Os principais objetivos deste projeto são:

* Compreender o conceito de Engenharia de Prompts;
* Identificar os principais elementos de um prompt eficiente;
* Conhecer diferentes técnicas de prompting;
* Investigar a importância do contexto nas interações com modelos de IA;
* Experimentar diferentes formas de estruturar uma mesma solicitação;
* Comparar os resultados obtidos após o refinamento dos prompts;
* Desenvolver prompts reutilizáveis para futuras sessões de estudo;
* Utilizar a IA de forma crítica como apoio ao processo de aprendizagem;
* Documentar os aprendizados, dificuldades e decisões tomadas durante o projeto.



Contexto

Com o crescimento das ferramentas baseadas em Inteligência Artificial Generativa, saber formular boas instruções tornou-se uma habilidade cada vez mais importante.

Entretanto, utilizar IA não significa apenas fazer perguntas e aceitar automaticamente as respostas recebidas.

Um processo de aprendizagem mais ativo envolve:

>Pesquisar → Formular perguntas → Testar → Analisar → Comparar → Refinar → Consolidar o conhecimento.

A Engenharia de Prompts está diretamente relacionada a esse processo, pois permite estruturar melhor a comunicação com modelos de linguagem e definir com maior clareza o objetivo esperado.



Metodologia

O desenvolvimento deste caderno temático foi realizado seguindo as etapas abaixo:

1. Escolha do tema

Foi selecionado o tema Engenharia de Prompts para IA Generativa, considerando sua relevância para o uso consciente e eficiente de ferramentas de Inteligência Artificial.

2. Curadoria de fontes

Foram selecionadas fontes abertas e confiáveis, priorizando materiais oficiais e conteúdos relacionados diretamente ao tema estudado.

3. Organização no NotebookLM

As fontes selecionadas foram inseridas no NotebookLM para apoiar a realização de perguntas, sínteses e conexões entre os conteúdos.

4. Formulação de perguntas

Foram elaboradas perguntas estratégicas com diferentes níveis de detalhamento para investigar os conceitos presentes nas fontes.

5. Experimentação com prompts

Uma mesma tarefa foi executada utilizando diferentes versões de prompts.

As variações incluíram:

* Perguntas genéricas;
* Adição de contexto;
* Definição do público;
* Especificação do formato;
* Inclusão de restrições;
* Solicitação de exemplos;
* Refinamento iterativo.

6. Análise dos resultados

As respostas foram analisadas considerando aspectos como:

* Clareza;
* Organização;
* Relevância;
* Nível de detalhamento;
* Adequação ao objetivo;
* Relação com as fontes.

7. Consolidação

Os principais conceitos e aprendizados foram organizados em um **Miniguia de Estudos**.

Cicatrizes e Troubleshooting

Nem todos os primeiros resultados foram considerados ideais.

Entre as principais dificuldades encontradas durante a experimentação estão:

* Respostas excessivamente genéricas;
* Falta de estrutura;
* Nível de profundidade diferente do esperado;
* Repetição de informações;
* Ausência de exemplos;
* Respostas que não atendiam completamente ao objetivo definido.

Para solucionar esses problemas, os prompts foram refinados através da inclusão de:

* Contexto;
* Público-alvo;
* Objetivo explícito;
* Formato esperado;
* Restrições;
* Critérios de qualidade.

Essa etapa demonstrou que a criação de prompts é um processo iterativo.

Principais Aprendizados

Durante o desenvolvimento deste projeto, foi possível concluir que:

* Um prompt eficiente não precisa necessariamente ser longo;
* Clareza é mais importante do que complexidade;
* O contexto influencia a relevância das respostas;
* Definir o objetivo ajuda a reduzir ambiguidades;
* Especificar o formato facilita a obtenção de resultados organizados;
* Exemplos podem ajudar a demonstrar o resultado esperado;
* O refinamento iterativo melhora progressivamente a qualidade das respostas;
* As respostas produzidas por IA devem ser analisadas criticamente;
* Fontes confiáveis são fundamentais para uma aprendizagem mais consistente.

Conclusão

A realização deste projeto demonstrou que a Inteligência Artificial pode ser utilizada como uma ferramenta de aprendizagem ativa quando seu uso é acompanhado de pensamento crítico, curadoria de fontes e validação das informações.

A principal conclusão obtida é que a Engenharia de Prompts não consiste simplesmente em escrever comandos mais longos.

Um prompt eficiente depende da combinação entre objetivo claro, contexto relevante, instruções adequadas e critérios para avaliar o resultado.

Além disso, a qualidade da interação pode ser melhorada através de um processo contínuo de experimentação e refinamento.

> Aprender a utilizar a IA também significa aprender a questionar, avaliar e aprimorar os resultados que ela produz.
